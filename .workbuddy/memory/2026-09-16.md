## 【重要】红绿灯无动作根因定位 + 修复（用户提示"别的文件版本红绿灯可用"）
- 根因：本 fork 的红绿灯**不靠 `trafficLightState` 字段**，而靠"低速强制实验模式"让原生模型停止线/信号灯分支生效（controlsd.py11 已验证可用的机制：5~70km/h → scene_mode=3 → force_experimental_mode → experimental_mode=True）。
- 当前版本（py1 基底）的低速强制条件写的是**定速** `v_cruise_kph < TL_LOW_SPEED_FORCE_EXP_KPH(30) and v_ego_kph<60`；市区巡航设 50~70 时该条件永不成立 → 实验模式不被强制 → 主路径（trafficLightState）本 fork 又没有 → 红绿灯彻底无动作。
- 修复（controlsd.py）：
  - 新增常量 `TL_LOW_SPEED_MIN_KPH=5.0`、`TL_LOW_SPEED_MAX_KPH=70.0`（按实际车速判定）。
  - 在 `state_control` 的 `if self.enabled:` 块内（use_stock_acc 之后、弯道检测之前）加入 `if TL_LOW_SPEED_MIN_KPH <= v_ego_kph < TL_LOW_SPEED_MAX_KPH: self.experimental_mode = True`（对齐 py11，且不依赖 openpilotLongitudinalControl 门控）。
  - 保留原 TL 状态机作为增强：有 trafficLightState 时走精确灯色状态机，没有则自动走低速实验模式主路径。
- py_compile + pyflakes 零告警。
- 指南第 8 节 A 段已更正：原表述把 trafficLightState 当硬前提是误导，现改为说明"低速强制实验模式为主路径 + trafficLightState 为增强项"，并记录了 v_cruise<30 的历史坑。
