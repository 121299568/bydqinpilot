# 2026-09-23

## 静态前车识别强化（用户需求：百分百识别前方静态车并刹车）
现状：SS 三源融合（视觉 lead + 低速雷达兜底 + HSA），最大漏洞是高速静止车视觉 prob<0.6 时 vision/雷达兜底都不触发→穿透。

改动（已语法校验通过，备份 *_bak_20260923_ss）：
- `radard.py` `get_lead()`：新增「无视觉确认的静止雷达前车」分支。条件：v_ego>=4m/s、yRel<1.0（正前本车道）、0.75<dRel<120m、|vLead|<0.5且 track.cnt>=8（持久性门限，抑制护栏/龙门架幽灵刹）。开关 `RADAR_STATIONARY_ENABLE`、常量 `RADAR_STATIONARY_*` 可调。
- `controlsd.py`：新增紧急静态前车安全网。确认 `_static_lead_active` 且 dRel<EMERGENCY_DIST_M(45m) 或 TTC<EMERGENCY_TTC_S(1.6s) → `_emergency_static=True`，a_min 强制 AC_EMERGENCY_MIN(-7.0)，并**绕过 ACCEL_SLEW_RATE** 立即重刹。开关 `EMERGENCY_STATIC_BRAKE`。
- 每帧重置 `_static_lead_active` 防止陈旧状态误触发；DEBUG_FEATURE_LOG 日志新增 `EMG act=` 字段。

残余风险（已告知用户）：视觉漏检（遮挡/雪天白车/无光照/恶劣天气）、雷达正前护栏持久回波可能幽灵刹。真·100% 物理不可能；出现幽灵刹先关 `RADAR_STATIONARY_ENABLE` 或 `EMERGENCY_STATIC_BRAKE`。

## 静态前车识别强化（第二轮，安全补全）
在首轮基础上继续堵漏，已语法校验通过（同一对 *_bak_20260923_ss 备份）：
- 视觉「疑似静止前车」软兜底：prob∈(0.35,0.6]、距离<20m、速度<2km/h 也按静态前车刹车（常量 VL_PROB_SUSPECT/VL_SUSPECT_DIST_M/VL_SUSPECT_STOP_KPH）。重构视觉块外层守卫，使该分支不再被 `prob>VL_PROB` 卡死。
- 视觉确认的静止前车也点亮 `_static_lead_active`（原仅雷达分支点亮）→ 紧急安全网覆盖纯视觉场景；并加 `vision_static` 标志，防止雷达(运动 lead)把视觉已置位的静态标志误清。
- 正常停前车刹车 AC_SL_MIN 由 -3.0 提到 -4.5（停车距离更短，仍在 OP 正常包络）。
- 紧急安全网新增「a_req>|AC_SL_MIN|」触发条件：只要当前距离内 -4.5 已停不住就强制 -7.0，数学上保证有足够刹车；并绕过 ACCEL_SLEW_RATE 立即重刹。
- 确认静态前车/紧急时**立即切 OP 纵向**（跳过 ACC_TAKEOVER_IN_T=0.3s 切入防抖），交回仍走 1.5s OUT 防抖；避免 stock ACC 接管期错过刹车时机。
- DEBUG_FEATURE_LOG 日志已含 `EMG act=`。
